# Buscar y explorar

## Buscar versículos

Abre **Buscar** y escribe una palabra o frase. Puedes reducir los resultados por testamento y libro. Las búsquedas recientes se conservan localmente para facilitar consultas repetidas.

Toca un resultado para abrirlo en el lector. Si una búsqueda no devuelve resultados, prueba una expresión más breve, quita filtros o cambia la versión bíblica.

## Explorar temas

La búsqueda también reconoce temas bíblicos. Los temas disponibles se organizan por categorías y muestran referencias que puedes abrir directamente en el lector. Las coincidencias por alias o nombre ayudan a encontrar un tema aunque no uses exactamente el título almacenado.

## Consultar el diccionario

El diccionario local reúne entradas sobre personas, lugares, conceptos, objetos, prácticas, eventos y libros. Busca un término, abre su ficha y revisa la definición y los metadatos disponibles.

::: tip Para interpretar mejor un resultado
Una definición o una referencia relacionada es un punto de partida. Antes de usarla en una enseñanza, lee el pasaje completo y verifica que responde a tu pregunta.
:::
