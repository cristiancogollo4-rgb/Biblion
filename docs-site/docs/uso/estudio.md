# Crear enseñanzas

El **modo estudio** combina la Biblia con un editor de documentos. Está diseñado principalmente para tablets y también ofrece una disposición compacta en teléfonos.

## De la idea al documento

1. Entra a **Estudio** y crea una enseñanza.
2. Escribe un título y desarrolla el contenido mediante párrafos, encabezados, listas, citas y versículos.
3. Aplica formato al texto cuando ayude a comprender la estructura: énfasis, color, resaltado, fuente o alineación.
4. Añade etiquetas de propósito, audiencia, tema y estado para organizarla.
5. Usa **Guardar** cuando quieras incluirla en **Mis enseñanzas**.

El editor conserva un borrador local automáticamente mientras trabajas. Un borrador sin publicar no aparece en **Mis enseñanzas** ni se sincroniza con Firestore. El guardado explícito exige un título.

## Lectura y edición

Puedes abrir una enseñanza guardada para leerla o editarla. El documento está dividido en bloques y se presenta en hojas paginadas. El zoom modifica la vista de trabajo; no cambia por sí solo el contenido guardado.

::: warning Alcance de la fase 1
«Publicar» dentro del editor significa guardar la enseñanza para tu biblioteca y, cuando corresponda, sincronizarla con tu cuenta. Todavía no la hace visible para seguidores ni habilita comentarios o valoraciones públicas.
:::
