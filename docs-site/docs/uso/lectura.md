# Lectura bíblica

## Abre un pasaje

Desde **Inicio**, selecciona un testamento, un libro y un capítulo. En la lista de libros, una pulsación prolongada abre una ficha con la descripción del libro. En el lector, toca el nombre o número del capítulo para elegir otro pasaje.

El texto bíblico principal se consulta desde las bases de datos incluidas en la aplicación, por lo que la lectura no depende de una solicitud a Firestore por cada versículo.

## Cambia la presentación

El lector permite ajustar la versión, el tamaño y estilo del texto, el espaciado entre líneas y el ancho de lectura. La vista de ejemplo de los ajustes sirve para comprobar el resultado antes de volver al pasaje.

En **lectura continua** puedes pasar al capítulo siguiente o regresar al anterior al desplazarte. El indicador superior debe reflejar el capítulo que estás leyendo, incluso al volver atrás.

En **lectura paralela**, cada panel puede navegar de forma independiente por libro, capítulo y versión. Al activarla, el segundo panel parte del pasaje actual; después puedes cambiarlo sin mover el primero. En pantallas compactas, la disposición se adapta al espacio disponible.

::: warning Disponibilidad de textos
No todas las versiones contienen todos los libros. Si falta un texto en la versión elegida, Biblion debe avisarlo y permitir seleccionar otra versión; no debe mostrar un pasaje inventado.
:::

## Selecciona y resalta

Mantén presionado un versículo para comenzar la selección. Después puedes tocar otros versículos para ampliar el conjunto. Desde las acciones disponibles puedes resaltar, agrupar una cita o usar el pasaje como contexto para Bibi y el modo estudio.

Si solo tocas un versículo cuando no hay selección activa, no debería quedar seleccionado. Esta diferencia evita selecciones accidentales durante la lectura.

## Consulta referencias cruzadas

Algunos versículos tienen referencias relacionadas en la base local. Abre su indicador para revisar los pasajes vinculados y navegar hacia ellos. La relación orienta la exploración; conviene leer siempre el versículo de destino dentro de su contexto.

## Si algo no se ve bien

- Comprueba la versión seleccionada cuando un libro no cargue.
- Si un resaltado parece tener un color incorrecto al cambiar de capítulo, espera a que el capítulo termine de tomar el foco y vuelve a comprobarlo.
- Si la lectura continua queda cargando, anota libro, capítulo, versión y dirección del desplazamiento antes de reportarlo.
