# Primeros pasos

Biblion reúne lectura bíblica, búsqueda, consulta y preparación de enseñanzas en una aplicación Android. La fase 1 está en desarrollo activo; algunas pantallas pueden cambiar mientras se validan en dispositivos.

## Comienza por la lectura

1. En **Inicio**, elige el Antiguo o el Nuevo Testamento.
2. Abre un libro y selecciona el capítulo que deseas leer.
3. Usa el selector de versión para consultar otra traducción disponible.
4. Mantén presionado un versículo para seleccionarlo. Una vez iniciada la selección, toca otros versículos para añadirlos.

En la primera instalación, Bibi presenta un recorrido guiado. Puedes volver a iniciarlo desde **Perfil → Reiniciar tutorial de lectura**. Si un elemento queda fuera de la vista, desplázate por la lista hasta encontrarlo.

::: tip Una aclaración sobre «publicar»
En esta fase, guardar una enseñanza la hace visible en **Mis enseñanzas** y permite sincronizarla con tu cuenta. No la publica todavía en un repositorio abierto a otros usuarios; eso corresponde a la fase 2.
:::
