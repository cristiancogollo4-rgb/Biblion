# Consultar a Bibi

Bibi acompaña la lectura y el modo estudio. Puedes preguntarle por un personaje, lugar, término, pasaje o tema bíblico. Si seleccionas un versículo antes de abrirla, ese texto puede aportar contexto a la conversación.

## Cómo responder mejor

- Formula una pregunta concreta: «¿Qué significa este término en el pasaje?» o «¿Qué relación tiene este versículo con el capítulo?».
- Cuando preguntes por una denominación o una doctrina, nómbrala expresamente. Bibi debe distinguir entre describir una postura y afirmar una verdad absoluta.
- Si una afirmación depende de una fuente externa no verificada, compruébala antes de usarla.

Bibi consulta primero recursos locales. Cuando la respuesta requiere profundización y la red está disponible, puede acudir al servicio remoto de IA. Por eso el tiempo de respuesta y el nivel de detalle pueden variar.

## Qué no debes asumir

Bibi puede equivocarse. No sustituyas la lectura del pasaje ni la revisión de fuentes por una respuesta automática. No debe inventar citas bíblicas, traducciones, hechos sobre denominaciones ni mensajes personales atribuidos a Dios.

::: warning Verifica antes de enseñar
Si una respuesta atribuye una creencia a una iglesia o presenta una interpretación debatida como indiscutible, contrástala con fuentes oficiales de esa tradición y con los textos bíblicos pertinentes.
:::
